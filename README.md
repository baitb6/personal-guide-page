# Bai · 个人引导页（照片墙 + 留言板）

一个精美的个人引导页 / 导航页，支持：

- 🎨 毛玻璃卡片风格 + 动态背景
- 📸 照片墙（上传、点赞、说明文字）
- 💬 留言板（发表、点赞）
- 📱 完美适配手机与桌面
- 🔗 可自定义社交链接入口

## 演示

当前线上示例：http://slongb.xyz

## 技术栈

- 前端：原生 HTML + CSS + JavaScript
- 后端：PHP（纯原生，无框架）
- 数据库：MySQL / MariaDB

## 目录结构

```
.
├── index.html          # 前端页面
├── api/
│   ├── config.php      # 数据库配置（请修改）
│   ├── db.php          # 数据库连接与自动建表
│   ├── get.php         # 获取留言列表
│   ├── post.php        # 发表留言
│   └── photos.php      # 照片墙 API（列表 / 上传 / 点赞）
└── photos/             # 上传的照片存放目录（需可写）
```

## 部署步骤

1. **准备环境**
   - PHP 7.4+（推荐 8.x）
   - MySQL 5.7+ / MariaDB
   - 支持 `pdo_mysql` 扩展

2. **上传文件**
   - 将整个项目上传到网站根目录（或子目录）
   - 确保 `photos/` 目录存在且对 PHP 进程可写（`chmod 755` 或 `775`）

3. **配置数据库**
   - 复制并编辑 `api/config.php`，填入你的数据库信息
   - 首次访问时会自动创建 `messages` 和 `photos` 表

4. **访问**
   - 打开你的域名即可看到引导页

## 功能说明

### 留言板
- 支持匿名或自定义昵称
- 内容最长 100 字
- 同一 IP 10 秒内只能发一条（防刷）
- 支持点赞

### 照片墙
- 支持 JPG / PNG / WebP / GIF
- 自动压缩过大图片（需要 GD 扩展）
- 可添加说明文字
- 支持点赞

## 注意事项

- 本项目不包含任何框架依赖，体积小、部署简单
- 生产环境建议开启 HTTPS
- 如需修改前端样式或链接，直接编辑 `index.html` 即可
- 上传的照片会保存在 `photos/` 目录，请定期备份
